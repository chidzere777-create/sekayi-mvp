# SEKAYI MVP 1.0

## Simple • Local • Trusted

### Product
Sekayi is a Zimbabwe-focused marketplace connecting buyers and sellers.

## MVP Goal

Prove that real people can use Sekayi to discover products, sell products, and place orders.

## User Roles

### Buyer
- Register and log in
- Browse products
- Search products
- View product details
- Add products to cart
- Checkout
- Place orders
- View orders

### Seller
- Register
- Create a shop
- Add products
- Upload product images
- Set prices
- Manage stock
- View orders
- Update order status

### Admin
- View users
- View sellers
- Approve sellers
- View products
- Manage inappropriate products
- View orders

## Core Screens

1. Welcome
2. Login / Register
3. Home
4. Search
5. Product Details
6. Cart
7. Checkout
8. My Orders
9. Seller Dashboard
10. Add Product

## MVP Payment

Initial payment options:
- Cash on Delivery
- Manual payment confirmation

Digital payment integrations can be added after validation.

## MVP Order Status

- Pending
- Confirmed
- Preparing
- Out for Delivery
- Delivered
- Cancelled
